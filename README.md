# Expense Tracker Lite 💰

A simple, modern, and responsive personal expense tracker web app built with **Python (Flask)**, **SQLite**, **Tailwind CSS**, and **Chart.js**.

---

### 🌐 Live Application
👉 **[Click here to view the Live Demo](https://expense-tracker-lite-i3x8.onrender.com)**

---

## ✨ Key Features

- 📊 **Interactive Dashboard:** Category spending breakdown (Donut, Pie, Polar Area charts) and daily spending trends (Bar & Line charts).
- 🎯 **Monthly Budget:** Track your monthly spending limit with live visual progress and alerts.
- 🔄 **Recurring Expenses:** Manage subscriptions and recurring monthly payments easily.
- 🏆 **Savings Goals:** Set target goals and track your savings progress.
- 📑 **Export Reports:** Download filtered expense reports directly as **CSV** or **PDF**.
- 🔐 **Authentication:** User signup, secure login, and password recovery.
- 🌓 **Dark & Light Mode:** Toggle between sleek dark and clean light themes.

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask), Flask-SQLAlchemy, Flask-Login, ReportLab
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript, Chart.js
- **Database:** SQLite
- **Deployment:** Render + Gunicorn

---

## 🚀 Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/GarimaVerma45/EXPENSE-TRACKER.git
cd EXPENSE-TRACKER
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Start the app
```bash
python app.py
```
Open **http://127.0.0.1:5000** in your browser.
